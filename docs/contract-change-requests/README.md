# Contract Change Requests

The interfaces on `langgraph-interface-v1` are frozen for parallel work. Do
not edit canonical contracts, graph state, protocols, or node names in a
feature branch.

If an interface blocks implementation, add an entry to your assigned file:

- Person 1: `PERSON_1.md`
- Person 2: `PERSON_2.md`
- Person 3: `PERSON_3.md`

Each request must include the affected symbol, exact proposed change, reason,
compatibility impact, and one example payload or call. Continue behind a
private adapter when possible. Person 1 resolves accepted requests once during
final integration.
